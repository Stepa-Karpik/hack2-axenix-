# Mandatory language acceptance fixture

These seventeen deterministic console contracts were independently hand derived before any execution. Expected stderr is empty and exit is zero in every case. `oracles.json` is input to the acceptance test, never generated from the analyzer, a baseline run or a Java compiler. Only the Docker runner may compile or execute Main.java.

- Dispatch: first Child construction initializes Base then Child (`BS`); Base instance initializer/constructor precede Child's (`bCsD`). Override on an int argument returns four; the Integer overload inherited from Base returns thirteen; static field is four; interface dispatch with three returns six. Initializer bodies are behavior observations, not expanded initializer CFG claims.
- Numbers: int/long MAX plus one wrap to MIN. Narrowing255 to byte gives -1; byte127 plus int3 promotes to130. Cyrillic А plus one is Б; double -3.9 cast to int truncates toward zero. Null Integer unboxing is caught. This fixture does not claim all numeric corner cases such as NaN/infinities.
- Arrays: an alias changes first row's second element to9; adding second row's3 gives12. Outer length2, short row length1, empty length0. Invalid short-row index prints B; null length prints N.
- Conditions: each mode calls tick exactly once. True uses postincrement giving chosen1/final2; false uses preincrement giving chosen2/final2. Library calls and ternary are selectable AST projections; the test does not assert expanded interprocedural expression CFG.
- Strings: parse12 plus abs(-3) is15. StringBuilder yields Привет:15; six UTF16 characters, prefix matches, boxed A unboxes to code65.
- Scanner: three tokens -1/0/MAX, then consume the token-line newline before reading Привет. Final hasNext sees EOF. Empty input is EOF, invalid integer throws the caught InputMismatchException. UTF8 is explicit in Scanner; runner stdin is closed after exact bytes.
- Formatting: Locale.ROOT forces decimal dots; integer width four pads3 to0003. `%n` means LF in the pinned Linux Docker runner, not a claim about a Windows host JVM. Both Formatter and printf are exercised.
- Collections: Iterator.remove drops only null from [a,null,a,b]. LinkedHashMap replaces x's value without moving its key, linked set deduplicates in insertion order. The concrete ArrayList iterator detects add-after-iterator and prints C. This is not a universal promise about every collection's fail-fast behavior.
- Comparator: named class sorts descending key, ascending name; List.sort preserves first/second input order for equal key+name. Negating Integer.compare's -1/0/1 is safe. No lambda/anonymous class capability is required.
- Optional: eager fallback executes even for present V; both cases therefore report one effect, differing only selected result/presence.
- Exceptions: raising prints T, then checked catches C or unchecked catches U; mode2 prints N. Every path prints F from finally. Exceptions are caught so stderr stays empty; uncaught stacktrace normalization is not covered.

`acceptanceLanguage.spec.ts` creates11 own projects, one equivalent expression edit per domain, checks source ranges and methods, exact changed source/unchanged companion, detached heads and fresh candidate analysis, then real compile and three baseline plus three candidate observations per case. This costs17 ×6 =102 runtime observations plus11 candidate and22 comparison compilation requests. Parenthesizing the actually exercised construct is an equivalent AST edit; no marker-only edits are used. Parse/graph/edit/emit/compile/behavior proof is bounded to these concrete forms. JDK/library calls remain atomic and source-preserved. No performance claim, complete mandatory matrix pass or organizer test pass follows from this fixture.

With the local application and isolated runner running, execute `pnpm --filter @java-blueprints/web exec playwright test tests/acceptanceLanguage.spec.ts`. An unavailable runner fails this suite. Fixture Java is compiled and executed only through the application's Docker runner.
